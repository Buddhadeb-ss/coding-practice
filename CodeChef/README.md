# CodeChef Solutions

This directory contains solutions to problems solved on [CodeChef](https://www.codechef.com/), automatically synchronized into this repository using the **CP Sync** extension.

## Directory Structure

Solutions are organized by programming language:

```text
CodeChef/
├── README.md
├── C/              # Solutions written in C (.c)
├── Cpp/            # Solutions written in C++ (.cpp)
├── Python/         # Solutions written in Python (.py)
├── Java/           # Solutions written in Java (.java)
└── ...
```

## Naming Convention

Each solution is saved with a descriptive, filesystem-safe filename:
`[ProblemCode] - [ProblemTitle].[ext]`  
*(e.g., `START01 - Number Mirror.c` or `FLOW001 - Add Two Numbers.cpp`)*

## Solution Metadata

Each synchronized file includes a header comment block preserving key submission metadata:
- **Problem Name & Code**
- **Platform** (CodeChef)
- **Programming Language**
- **Verdict** (Accepted)
- **Problem URL**
- **Submission ID & Submission URL** (when available)
- **Date / Timestamp**
